План API: Платежи

| Поле                | Тип      | Кто задаёт   | Правило                         |
|---------------------|----------|--------------|---------------------------------|
| Id                  | int      | сервер       | —                               |
| RoditelId           | int      | пользователь | обязательно, больше 0           |
| RebenokId           | int      | пользователь | обязательно, больше 0           |
| KolichestvoZanyatiy | int      | пользователь | от 1 до 12                      |
| Summa               | decimal  | пользователь | от 500 до 100000                |
| Status              | string   | сервер       | при создании — «Не оплачено»    |
| CreatedAt           | DateTime | сервер       | текущее время                   |

| Метод  | Адрес             | Действие        | Коды ответа   |
|--------|-------------------|-----------------|---------------|
| GET    | /api/oplatas      | Список платежей | 200           |
| GET    | /api/oplatas/{id} | Один платёж     | 200, 404      |
| POST   | /api/oplatas      | Создать платёж  | 201, 400      |
| DELETE | /api/oplatas/{id} | Удалить платёж  | 204, 404, 409 |

Бизнес-правило: платёж в статусе «Оплачено» нельзя удалить → 409.
