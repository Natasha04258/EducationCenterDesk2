EducationCenterDesk
Состав решения:

1. EducationCenterApi: серверная часть на ASP.NET Core Web API для хранения и обработки платежей.
2. EducationCenterDesk: клиентское приложение Windows Forms для просмотра и добавления оплат.

Требования:

1. Visual Studio 2022
2. .NET 9.0 для сервера и .NET Framework 4.8 для клиентского приложения

Как запустить

1. Откройте проект EducationCenterApi в Visual Studio, выберите профиль http и нажмите F5. Сервер запустится по адресу http://localhost:5257.
2. Откройте проект EducationCenterDesk и запустите его по клавише F5.
3. Нажмите кнопку Загрузить в главном окне для получения списка платежей.

Адреса API:

Документация Swagger доступна по адресу: http://localhost:5257/swagger

1. GET /api/oplatas: получить список всех платежей
2. GET /api/oplatas/{id}: получить платёж по ID
3. POST /api/oplatas: добавить новый платёж
4. DELETE /api/oplatas/{id}: удалить платёж по ID

Справка для пользователя:

1. В окне программы работают всплывающие подсказки при наведении мыши, примеры ввода в полях, значки ошибок и справка по клавише F1.
2. Руководство пользователя открывается из меню Справка и находится в файле EducationCenterDesk/Help/index.html.
