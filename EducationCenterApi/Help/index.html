Руководство пользователя EducationCenterDesk

1. Назначение программы

Программа предназначена для администратора учебного центра и используется для просмотра и добавления оплат за занятия.

2. Подготовка к работе

  1. Запустите сервер EducationCenterApi (порт 5257).
  2. Откройте клиентское приложение EducationCenterDesk.

3. Описание операций

Просмотр списка: нажмите кнопку «Загрузить» и дождитесь обновления таблицы.

Отмена загрузки: во время загрузки нажмите кнопку «Отмена».

Добавление платежа: заполните поля «ID родителя», «ID ребёнка», «Кол-во занятий» (1–12), «Сумма» (500–100000) и нажмите «Добавить».

5. Вопросы и ответы

Почему пропали записи после перезапуска? Сервер хранит данные в оперативной памяти, при перезапуске возвращаются начальные записи.

Как открыть подсказку по полю? Поставьте курсор в поле и нажмите клавишу F1.
